# ZAYVORA Health OS™ — Clinical Pilot Key Performance Indicators (KPIs)

**Document Reference:** ZAY-GOV-KPI-01  

| KPI Metric | Target Threshold | Measurement Frequency |
|---|---|---|
| **System Uptime** | >= 99.9% availability during clinic hours | Weekly |
| **Consultation Documentation Speed** | Average encounter charting time < 4 minutes | Weekly |
| **AI Recommendation Review Compliance**| 100% of prescriptions signed by clinician | Continuous |
| **Safety Firewall Interceptions** | 100% of contraindications logged and reviewed | Continuous |
| **Patient Satisfaction (PROMs)** | >= 85% positive feedback via patient portal | Monthly |
