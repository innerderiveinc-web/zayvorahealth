# ZAYVORA Health OS™ — Security Incident Response Plan

**Plan Reference:** ZAY-SEC-IRP-01  

## 1. Incident Severity Classification
- Severity 1 (Critical): Active data exfiltration, ransomware, total system outage, authentication bypass.
- Severity 2 (High): Unauthorized access to single tenant, localized clinical service failure.
- Severity 3 (Medium): Rate-limiting trigger, isolated bug without data exposure.

## 2. Response Workflow
1. Triage & Containment (Hour 0–1)
2. Investigation & Remediation (Hour 1–4)
3. Regulatory & Stakeholder Notification (Within 72 hours under DPDPB / CERT-In guidelines)
4. Post-Incident Review & Hardening
