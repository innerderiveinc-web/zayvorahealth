# ZAYVORA Health Mobile Application (v5.0 Enterprise)

Cross-platform React Native / Expo application for integrative patient self-management and clinician point-of-care decision support.

## Core Features
1. **Patient 360 & Personal Health Record (PHR)**: Longitudinal Mizaj monitoring, dominant organ-axis visualization, and condition trajectories.
2. **Vernacular Audio Posology**: Spoken medication guidance in Urdu, Hindi, and English for complex Unani formulations and anupan instructions.
3. **Asbab-e-Sittah الضرورية 6 Essentials Tracker**: Daily logging of Ambient Air (Hawa), Food & Drink (Makul wa Mashrub), Movement & Rest (Harakat wa Sukun Badani), Sleep (Nawm wa Yaqzah), Evacuation (Istifragh wa Ihtibas), and Psychic Reactions (Harakat Nafsaniyah).
4. **Tele-Consultation Booking**: Encrypted WebRTC consultation scheduling and physical Matab OPD slot reservation.
5. **Clinician Mobile Companion**: Rapid triage queue with non-delegable 21 CFR Part 11 cryptographic lock signature requirement.

## Run Locally
```bash
cd apps/mobile
npm install
npm run start
```
